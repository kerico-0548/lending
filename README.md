# Тест записи на занятия

Простая форма: имя и контакт. Записи сохраняются в серверной базе Cloudflare D1 (SQLite), а не в браузере или GitHub.

Сайт опубликован через Sites в режиме «только владелец». На странице видны последние 50 заявок. После обновления страницы данные повторно читаются из БД.

ВАЖНО: тестовая версия показывает контакты в списке заявок. Перед открытием публичного доступа необходимо закрыть список отдельной авторизацией администратора.

## Проверка
1. Откройте сайт и отправьте вымышленные имя и контакт.
2. Обновите страницу или откройте её на другом устройстве под тем же аккаунтом: запись останется.
3. Код хранится в GitHub; данные заявок в репозиторий не попадают.

## Разработка
Node.js 22.13+. Зависимостей нет.

- `npm test`: HTTP-проверки с настоящей локальной SQLite, включая сохранение после повторного открытия БД.
- `npm run build`: сборка Worker. Для запуска требуется D1-привязка DB и SQL-миграция из drizzle/.
- POST /api/applications: JSON с полями name, contact.
- GET /api/applications: последние 50 заявок.

Доступ к обоим маршрутам защищён внешней авторизацией Sites «только владелец». Сам Worker не предоставляет самостоятельную авторизацию и не должен размещаться публично в этом виде.
