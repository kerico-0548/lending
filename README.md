# Запись на занятие — GitHub Pages + Supabase

Сайт: https://kerico-0548.github.io/lending/

Статическая страница index.html отправляет имя и контакт напрямую в облачную базу Supabase. Аренда сервера и запуск компьютера не нужны. Заявки не хранятся в GitHub или браузере.

## Однократная настройка базы

1. Откройте свой проект Supabase → SQL Editor → New query.
2. Вставьте содержимое supabase/setup.sql и нажмите Run. Запустите файл один раз в новом проекте: он создаёт таблицу lesson_applications и разрешает посетителям только добавлять заявки.
3. Откройте сайт и отправьте вымышленные данные.
4. В Supabase → Table Editor → lesson_applications появится строка. Обновите список, если таблица была открыта до отправки.

config.js содержит Project URL и публичный Publishable key. Он предназначен для размещения в браузере. Secret key, service_role и пароль БД в код не добавляются.

Чтение, изменение и удаление заявок для посетителей запрещены. Список контактов доступен владельцу через Supabase Dashboard. Это простой тест без защиты от массовой отправки заявок; перед реальным использованием стоит добавить защиту от спама.

## Файлы страницы

- index.html — форма.
- app.js — проверка ввода и отправка заявки.
- config.js — публичные параметры Supabase.
- supabase/setup.sql — создание таблицы, ограничений и прав.
- .nojekyll — публикация обычных файлов через GitHub Pages.

Для Pages выбраны main и / (root); сборка не требуется.

Папки worker/, drizzle/, scripts/, tests/ и .openai/ относятся к первой версии с Cloudflare D1 через Sites. GitHub Pages их не выполняет. Старая версия Sites и её БД существуют отдельно; заявки между двумя базами автоматически не переносятся.
